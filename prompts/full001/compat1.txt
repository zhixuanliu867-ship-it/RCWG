RCWG_FULL001_COMPAT1 is the selected public implementation profile. The protected legacy examples remain illustrative. The following versioned rules supersede conflicting legacy planning cards only for this profile.

1. Source capabilities occur in external_inputs and node inputs, never arbitrary paths or params.source. Output schemas and graph domains are derived by the compiler. No provider, model, endpoint, authentication, hidden labels or verifier controls are plan parameters.
2. project supports params.columns, source_view, representation, expressions and field_map. representation is same/table/record/set. Record representation requires exactly one row when converting from a table. Set representation projects one declared field. expressions maps new output field names to typed expression ASTs; leaves are {"field":"name"} or {"literal":value}; arithmetic uses {"op":"add|sub|mul|div","left":AST,"right":AST}. Existing predicate null, overflow and finite-number rules remain.
3. To pack multiple input ports into one Record, project params must contain exactly {"representation":"record","field_map":{"output_field":"input_port"}}; every supplied input port is mapped and output field names are unique. Input capability identities survive packing.
4. A node may declare param_bindings:[{"parameter":"name","ref":"producer.port","field":"optional_record_field"}]. A parameter has one source and is absent from static params when bound. The reference adds a data dependency. Only registered Int64/Utf8 value parameters can be bound. Algorithms, types, storage, paths and semantic-service identity cannot be bound.
5. Bindable parameters: top_k.k; text_retrieve.query/limit/offset; semantic_extract.question/context_budget; split_documents.size/overlap; gather_context.window; read_documents.batch_size; stream_read.batch_size; collect.limit; graph_reachability.max_hops; stats.sample_size. Values must pass the same type/range checks at execution as static values. No implicit cast.
6. top_k additionally supports partition_by as a list of existing group fields, including an empty list for global top-k. It returns exact top-k within each partition with the declared sort keys. text_retrieve additionally supports nonnegative offset, applied after score-descending/document-ID-ascending ranking. semantic_extract additionally supports question as a public Utf8 value. Its service remains the runner-bound E0 (or the separately registered E7 executor).
7. A view must explicitly select a declared public source_view when its schema comes from graph edges, graph nodes, document IDs or provenance. Column selection alone cannot invent an unregistered domain bridge. Read_documents returns only requested public fields; canonical_text or sections must be selected before semantic processing.
8. Keep native algorithms, explicit memory/disk materialization, shared_ref/copy_each and original node serialization choices as authored. No automatic plan repair, algorithm substitution or filter pushdown is supplied by the runtime. Limits remain 48 recursive logical nodes, region depth 2, loop maximum 16, 4096 cumulative node instances, and the public CPU/RAM/wall budgets.
