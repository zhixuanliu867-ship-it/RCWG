# 本轮预算与平台选择

核查日期：2026-09-18。报价为官方网页公开按量价格，不包含合同折扣、税费或账号特定优惠；部署前复核目标region与实际账单币种。文中金额是规划值，非已发生费用。

## 选择建议

本轮选 Google Cloud：Workflows负责外层YAML，Cloud Run Jobs负责短时工程执行，Cloud Storage保存私有产物。阿里云 CloudFlow + Function Compute + OSS 作为备用；当前只维护一套云部署。云平台与模型API厂商分别选择。

Google Workflows 的超额内部步骤每1,000步 USD0.01，外部步骤每1,000步USD0.025；每月内部5,000步、外部2,000步免费，存在千步取整。阿里云国际站 CloudFlow 公示每10,000次状态转换USD0.25，每月5,000次免费。实际工作流含轮询/重试，不能把DAG节点数直接视为账单步数。来源[S1][S3]。

以 Cloud Run Jobs 的 us-central1 普通按量价格估算，2vCPU+4GiB持续执行50小时的CPU/RAM计算项为 USD7.92，尚未扣除可用免费额度，也不含网络、存储、镜像和日志。Job存在最短计费时长；重复短任务不能仅按业务函数的毫秒数估算。来源[S2]。

阿里云FC国际站公开标准CU价格为USD0.000020/CU；之前USD0.000016的限时优惠已于2026-08-27结束。账户站点、资源折算、每小时最低费用和网络费用一起影响最终报价，不能把过期优惠当成本轮基价。来源[S4]。

## 控费门禁

Google alerts-only budget不会自动截断消费。当前 spend cap budgets 处于预览，支持含Cloud Run、Gemini API在内的部分服务，按单项目+单服务配置；估计费用、在途请求、持久资源与执行延迟意味着它也不能保证无超支。支持时可为Cloud Run设置USD10级别的小额验收cap，再逐服务配置正式额度。对象存储、镜像、其他厂商API和跨月累计需另外跟踪。来源[S5][S6]。

本包任务数1、并行1、Job重试0、超时120秒，默认不建立定时/事件触发器。Workflows连接器仍有平台自身的行为和轮询计费，本模板不承诺分布式exactly-once。云Job不具备真实模型调用入口与密钥。

真实API探针在获批本地终端中单次执行；SQLite门禁在同一机器上累计最多5次探针、USD1.00的预留估计，每次预留不超过USD0.20。预留不是实际账单或跨机器上限；超时/失败的预留也保留。清空数据库、换机器或绕开CLI会绕过这个本地门禁，因此正式批次还需要集中预算账本。

首次预算复核记录提供商实际usage、接口价格、P1阶段数和失败重试数。当前包没有承诺完整23,040生成尝试和61,440核心执行都能落在USD150内。
