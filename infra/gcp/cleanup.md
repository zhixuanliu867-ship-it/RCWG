# 本轮清理顺序（操作者明确确认后执行）
1. 在 Workflows 页面停止继续提交；检查 Cloud Run Jobs 是否仍有执行中的任务。
2. 取消仍在运行的 BOOT 执行。删除工作流定义本身不等于取消已经运行的 Cloud Run Job。
3. 下载并核验 `gs://<bucket>/boot/.../report.json`，登记结果和对应镜像 digest。
4. 删除 `rcwg-boot-001` 工作流与 `rcwg-boot-smoke` Job；检查是否遗留手工创建的 VM。
5. 按项目所有者确认的保留期清理 Artifact Registry 镜像和构建临时文件。
6. 存储桶仅在所有者确认已归档后删除；检查软删除/版本保留带来的后续费用。
7. 撤销本轮不再需要的服务账号权限，复查各云与 API 提供商账单。

本包不包含自动删除命令。对于专门用于本轮、确认无其他数据的项目，可由所有者在控制台关闭整个项目。
